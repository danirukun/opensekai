# Video screen test files

Made by `scripts/make-test-videos.sh` for the B29 video screen tests. Each file is 2 s long, 64 × 36, and shows red, green, blue, and white for 0.5 s each. `vp9-alpha.webm` has alpha 0 in the left half and alpha 255 in the right half. `h264-turned.mp4` has a 90-degree display matrix. `h264-late-moov.mp4` has its `moov` box after `mdat`.

`expected.json` holds the values that the host parser (`parse_video`) and the renderer reader (`readVideoInfo`) must give for each file. The tests do not run ffmpeg.

ffmpeg: ffmpeg version 6.1.1-3ubuntu5 Copyright (c) 2000-2023 the FFmpeg developers
