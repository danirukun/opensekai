# REASONS: Environment import gaps

Analysis: [environment import gaps](../analysis/2026-10-25-environment-import-gaps.md). Issue: [#147](https://github.com/danirukun/opensekai/issues/147). Queue bundle B23. Parent contract: [environment import](2026-10-13-environment-import.md).

## R — Requirements

G1. A Rust integration test imports a generated multi-file folder through the service, reads the result through `GET /assets/{id}`, and compares it with `fixtures/scene-import/packed-room.glb`. With `OPENSEKAI_UPDATE_FIXTURES` set, the test writes the file first. The test also proves that the three source files have the same bytes after the import (R15).
G2. A renderer test reads `fixtures/scene-import/packed-room.glb`. `inspectContainer` returns no extensions and one image. `GLTFLoader` parses it to one mesh, and the image has `mimeType` and no `uri`.
G3. `pack_scene` tests cover: a file that is not `.glb`, `.gltf`, or `.zip` (R6); a zip with no root, and a zip with its root two folders down (R7); an unreferenced zip entry with a broken checksum, which does not stop the pack, and the same entry with a reference, which fails with `File unavailable` (R9).
G4. A `pack_scene` test packs each prepared fixture stage (`fixture_glb_stage`, `fixture_test_stage`) when setup downloaded it. The output passes `validate_glb`, has no `uri`, and has the same accessor, mesh, material, node, texture, and image counts as the source (R12).
G5. Registry tests cover a library file of the wrong length, which a new import writes again, and a title of 128 code units, which becomes the name (R14).
G6. A renderer test shows that an environment with `visible: false` draws nothing and shows again when it is visible (R16).
G7. `addLimitReached(kind, entities)` in `editor/authoring.ts` gives the disabled state of each Add menu item. The Hierarchy uses it. A test shows that Environment is disabled only while the scene has an environment (R20).
G8. `settleCheckbox(box, reply, current)` in `editor/live-fields.ts` sets the box to `current` when the reply is not `ok`. The Inspector uses it for Visible and Render Environment. A test covers both results (R24).
G9. A test shows that `importFailure(cause, 'Could not import model')` cuts an `AppError` message to 160 characters and gives the fallback for other causes (R22).
G10. A show test writes and reads a show with an environment whose `assetId` is unknown and a camera with `renderEnvironment: false`, and gets the same document (R26).
G11. R6 of the parent contract says that the dialog has no file-type filter on macOS and that `pack_scene` checks the extension.
