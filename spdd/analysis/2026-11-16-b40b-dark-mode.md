# B40b analysis: dark mode (UX-05 part, #183)

Date 2026-11-16. Base `06dce38`. [V] = verified. [I] = inferred.

## Owner decisions
- The default is System. The control is Settings › Appearance › Theme, with the options System, Light and Dark.
- Theme is only in Settings. It is not in the native View menu.
- The dark palette derives from the OpenSekai brand tokens (#289). The owner picks from PR screenshots.
- 2026-11-20: the owner picked B as Dark and kept A as a fourth choice, Dark Navy. System never resolves to Dark Navy.

## Current state
- `index.html:2` has `data-theme="dark"`. `main.ts:4` sets `light` before mount. The app has only the light theme. [V]
- The kit `theme.css` has a dark set on `html[data-theme='dark']`, with specificity (0,1,1). The app `:root` block has (0,1,0). The kit dark set wins over app tokens unless the app defines its own `html[data-theme='dark']` block after the kit import. [V]
- The kit `createThemePreference` has no system mode. [V] We do not use it.
- `app.css` `:root` (lines 4–30) has the brand tokens: lime, navy, lilac, cyan, and the neutral, semantic and primary tokens. [V] There are 252 token uses.
- Color literals outside the root block: 79 in 14 files. `app.css` holds 51 (34 distinct).
