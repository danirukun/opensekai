# Getting started

OpenSekai is a desktop editor for a VTuber scene. You put characters, a stage, lights, and cameras in a scene. OBS shows the output of the scene as a browser source with a transparent background.

## Start screen

When you start OpenSekai, the start screen shows on the Scene view. You can do these tasks from the start screen:

- Click **Add character** to add a character and select a VRM file for it.
- Click **Open show…** to open a show file.
- Under **Templates**, click a template (for example **Stage Lights**) to open a show that has a stage setup.
- Under **Recent**, click a show to open it again. The list has the last 5 shows.

To close the start screen, click **Close** (the X) or push Escape. The start screen also closes when you change the scene.

## Shows

A show is a file that keeps your scene and your Blueprints.

- To change the name of the show, type in the name field at the top of the editor.
- To save the show, click **Save show**. Hold Shift when you click to save the show to a new file.
- To open a different show, click **Open show**.

If the show has changes that you did not save, OpenSekai asks you before it quits.

## Editor layout

The rail on the left side of the window selects a panel:

- **Assets**: the asset list, the Scene view, and the Properties column. See [Scene](scene.md).
- **Output**: the OBS output. See [Cameras and output](cameras-and-output.md#output).
- **Blueprints**: the Blueprint editor. See [Blueprints](blueprints.md).
- **Resources**: the files that you imported. See [Settings and resources](settings.md#resources).
- **Settings**: integrations. See [Settings and resources](settings.md).

The mark at the top right of the window shows the session state.
