# Scene

The **Assets** panel has three parts. The asset list is on the left. The Scene view is in the middle. The Properties column is on the right.

## Asset list

The asset list shows each asset in the scene, in groups.

- To add an asset, click **Add asset** (the plus sign) and select an asset type.
- To select an asset, click it. You can also use the Up Arrow, Down Arrow, Home, and End keys.
- To find an asset, type a part of its name in the search field.

Right-click an asset to open its menu. The menu items change with the asset type:

- **Move**, **Rotate**, and **Scale** select a transform tool.
- **Start** and **Stop** control a tracking source or a VMC sender.
- **Hide** and **Show** change the visibility of the asset.
- **Use as output camera** sends a camera to the OBS output.
- **Reset position**, **Reset rotation**, and **Reset scale** set one part of the transform back to its default.
- **Rename**, **Duplicate**, and **Remove** change the asset itself.

A scene has a limit on the number of each asset type. When a limit is full, the menu item for that type is disabled.

## Scene view

The Scene view shows the scene through the selected camera.

- Click an asset in the Scene view to select it.
- Use the transform tools in the toolbar to move, rotate, or scale the selected asset. The keys are W (Move), E (Rotate), and R (Scale).
- Click **Guides** to show a center mark or thirds lines.
- Click the eye to stop or start the preview. When the preview is off, the output continues.

## Properties

The Properties column shows the settings of the selected asset. The Help button in the Properties header opens the page for the type of the selected asset.

- When the column has more sections than it can show, an index of the sections shows at the top. Click a section name to go to that section.
- Click a section header to collapse or expand the section.
- A reset mark shows next to a value that is different from its default. Click the mark to set the default value again.
