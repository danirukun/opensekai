# Settings and resources

## Settings

The **Settings** panel has the integrations with other services.

### YouTube

Type the link of your YouTube stream in **Stream link**. OpenSekai reads the public live chat of the stream. You do not sign in. The status line under the field shows the state of the connection.

Blueprints can use the YouTube events, for example a new chat message. See [Blueprints](blueprints.md).

## Resources

The **Resources** panel lists the files that you imported: characters, models, images, and videos. Each row shows the name, the format, and the license of the file.

If OpenSekai finds a problem with a file, a warning shows under the list.
