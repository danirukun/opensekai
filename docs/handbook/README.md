# OpenSekai handbook

This handbook tells you how to use the OpenSekai editor. Each panel of the editor has a Help button (the question mark at the right end of the panel header). The Help button opens the page for that panel.

OpenSekai is in development. The pages describe only the behavior that you can see in the app now. For the status of each feature, see [the parity checklist](../warudo-parity.md).

## Pages

- [Getting started](getting-started.md): the start screen, shows, and the editor layout.
- [Scene](scene.md): the asset list, the Scene view, and the transform tools.
- [Characters](characters.md): VRM models, expressions, meshes, and the idle animation.
- [Motion capture](motion-capture.md): tracking sources, the tracking guide, and the VMC sender.
- [Stage](stage.md): environments, props, lights, haze, screens, and the FPS counter.
- [Cameras and output](cameras-and-output.md): cameras, screenshots, and the OBS output.
- [Blueprints](blueprints.md): graphs that change the scene when an event occurs.
- [Settings and resources](settings.md): integrations and the list of imported files.
