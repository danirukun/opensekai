## Template

Copy this block into `NNNN-kebab-case-title.md`. Use the next free number.

    # NNNN. Title

    Status: Proposed
    Date: YYYY-MM-DD
    Owner: Name
    Related: #issue, spec path, ADR NNNN

    ## Context

    What problem do we have? What limits apply?

    ## Decision

    What do we do? Use short, active sentences.

    ## Options considered

    Each option, with the reason we chose it or did not choose it.

    ## Consequences

    What becomes easier, what becomes harder, and what follow-up work we must do.

    ## Open questions

    Questions that are not decided yet. Remove this section when it is empty.

    ## Sources

    Links to the documents and measurements that support the decision.
